## 🚀 Featured Projects

### 💸 [Remittance System](https://github.com/a-namoura/remittance-system)

**Full-Stack Application · Blockchain Integration**

A remittance prototype that combines a React interface, an Express API, MongoDB persistence, and Solidity smart contracts on BNB Smart Chain Testnet.

- Account and wallet flows, transfer requests, transaction history, and administration.
- Authenticated APIs, database persistence, and on-chain transaction reconciliation.

`React` · `Vite` · `Tailwind CSS` · `Node.js` · `Express` · `MongoDB` · `Solidity`

**[Explore the code and architecture →](https://github.com/a-namoura/remittance-system#architecture)**

<sub>Educational/testnet prototype; not a live financial service.</sub>

### 📊 [Personal Expense Tracker](https://github.com/a-namoura/expense-tracker)

**Full-Stack Application · Database Design**

An expense management application built for the Database II Lab at Al-Quds University, connecting a React frontend to an Express API and MongoDB.

- Registration and JWT-based authentication.
- Expense entry and management, with monthly totals grouped by category.

`React` · `JavaScript` · `Node.js` · `Express` · `MongoDB` · `Mongoose`

**[Explore the project →](https://github.com/a-namoura/expense-tracker)**

<sub>Educational project with additional security and deployment work documented in its README.</sub>
