## Projects

### [Remittance System](https://github.com/a-namoura/remittance-system) — Full-stack & blockchain

A React, Express, and MongoDB application with Solidity smart contracts targeting BNB Smart Chain Testnet.

- Wallet onboarding, send/request flows, and transaction tracking.
- API routes, background transaction reconciliation, and admin tooling.
- Solidity contracts and Hardhat tests for transfers and escrow.

**Stack:** React · Node.js · Express · MongoDB · Tailwind CSS · Solidity · Hardhat
