## Featured Full-Stack Projects

### 💸 [Remittance System](https://github.com/a-namoura/remittance-system)

A full-stack remittance prototype with account and wallet flows, transfer requests, transaction history, administrative features, and smart-contract integration.

- **Frontend:** React 19, Vite, Tailwind CSS
- **Backend:** Node.js, Express, MongoDB/Mongoose
- **Blockchain:** Solidity, Hardhat, ethers.js, BNB Smart Chain Testnet
- **Engineering focus:** authenticated APIs, persistence, transaction reconciliation, and frontend–backend integration

[Source code & architecture →](https://github.com/a-namoura/remittance-system#architecture)

*An educational/testnet implementation, not a live financial service.*

### 📊 [Personal Expense Tracker](https://github.com/a-namoura/expense-tracker)

A full-stack expense management application built for the Database II Lab at Al-Quds University.

- User registration and JWT-based login
- Expense entry, listing, and deletion
- Monthly spending summaries grouped by category using MongoDB aggregation
- React interface connected to an Express API

**Stack:** React · JavaScript · Node.js · Express · MongoDB · Mongoose

[Explore the project →](https://github.com/a-namoura/expense-tracker)

*An educational application with documented areas for further security and deployment work.*
